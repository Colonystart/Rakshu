BESTIE BIRTHDAY SURPRISE WEBSITE

1. Keep index.html and the assets folder together.
2. Open index.html in a browser to preview.
3. To publish, upload the entire folder contents to any static website host (Netlify, Cloudflare Pages, GitHub Pages, or Vercel).
4. The first screen is a gift-opening surprise. The photos and three videos appear after tapping "Open your surprise".
5. You can edit the birthday wording in index.html. Replace the generic greeting/sign-off with your bestie's name and your own message if you want.
